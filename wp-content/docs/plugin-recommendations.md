# Alafi Plugin Recommendations

## Core Commerce
- WooCommerce (required)
- WooCommerce Blocks
- WooCommerce Payments / Stripe
- Cashfree Payment Gateway for WooCommerce
- Razorpay for WooCommerce

## Search & Discovery
- Relevanssi
- ElasticPress (for ElasticSearch)
- Variation Swatches for WooCommerce
- YITH WooCommerce Compare

## Performance & Caching
- Redis Object Cache
- WP Rocket (pro) or LiteSpeed Cache
- Query Monitor (staging only)

## SEO, Analytics, Compliance
- Rank Math SEO
- Site Kit by Google (GA4 validation)
- CookieYes GDPR Cookie Consent
- WP Activity Log (admin audit)

## Security & Operations
- Wordfence Security
- WP 2FA
- WP Mail SMTP
- UpdraftPlus
